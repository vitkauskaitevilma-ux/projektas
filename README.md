# Ona Vi — fotografijos svetainė

Lietuviška fotografės Vilmos „Ona Vi“ svetainė: portretų galerija, paslaugos, prisistatymas, fotosesijos eiga ir kontaktai.

## Peržiūra ir redagavimas

Svetainė veikia be papildomų bibliotekų ar kūrimo žingsnio. Visas viešas turinys yra saugyklos šaknyje.

- `index.html` — tekstai ir puslapio struktūra.
- `style.css` — dizainas ir prisitaikymas prie telefono.
- `script.js` — meniu ir nuotraukų peržiūra.
- `assets/` — fotografijos ir piktograma.

Nuotraukos paimtos iš Vilmos anksčiau pateiktos portretų serijos gamtoje. Daugiau darbų galima pridėti pakeičiant arba papildant galeriją. Kontaktams naudojama patvirtinta „Instagram“ paskyra `ona.vi_photo`. Kainos, telefono numeris ir el. paštas nesugalvoti — juos galima įrašyti vėliau.

## GitHub Pages

„GitHub“ kopijoje svetainės failai pateikiami saugyklos šaknyje, kad būtų galima pasirinkti **Settings → Pages → Deploy from a branch → main → /(root)**.

Svetainė nekaupia lankytojų duomenų, neturi slapukų ar užklausų siuntimo serverio. Kontaktų mygtukai atidaro „Instagram“.
